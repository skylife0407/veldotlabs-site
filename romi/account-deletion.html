로미 계정 및 데이터 삭제

앱: 로미 (kr.romi.app) · 운영: 벨도트랩스 · 시행일 2026-10-11

로미 회원은 언제든지 계정과 관련 데이터를 삭제할 수 있습니다. 삭제는 즉시 처리되며 되돌릴 수 없습니다.

방법 1 — 앱에서 직접 탈퇴 (권장)

  1. 로미 앱 실행
  2. 하단 탭에서 내 정보 선택
  3. 화면 맨 아래 회원 탈퇴 선택
  4. 삭제되는 내용을 확인하고 다음 → 탈퇴하기

확인을 누르는 즉시 계정과 아래 데이터가 삭제됩니다.

카카오 연결을 끊은 경우

카카오로 가입했다면 카카오톡 설정 → 카카오계정 → 연결된 서비스 관리에서 로미 연결을 끊거나 카카오계정을 탈퇴해도 로미 회원 탈퇴로 처리됩니다. 아래 데이터가 똑같이 삭제되며, 처리할 때 앱 알림으로 알려 드립니다. (구글 등 다른 로그인도 연결된 계정은 카카오 연결만 해제되고 계정은 유지됩니다.)

방법 2 — 이메일로 요청

앱을 쓸 수 없는 경우 아래 이메일로 요청해 주세요.

contact@veldotlabs.com

  • 제목: [로미] 계정 삭제 요청
  • 본문: 가입한 방법(카카오 또는 휴대폰 번호)과 앱의 닉네임
이메일 요청은 본인 확인 후 영업일 기준 7일 이내에 처리하고 회신합니다.

삭제되는 데이터

  • 로그인 정보(카카오 회원 식별자, 휴대폰 번호, 이메일)
  • 프로필(닉네임, 성별, 출생연도, 키, 직업, 지역, 자기소개, 대화 카드, 이상형 조건, 직장 인증 정보)
  • 프로필 사진
  • 미팅 신청·참가·출석 기록, 투표, 메모
  • 매칭과 채팅 메시지 (상대방 화면에서도 사라집니다)
  • 신고·차단·'다시 안 만나기' 기록
  • 코인 내역과 남은 코인 (환불되지 않습니다), 광고 보상 지급 기록
  • 알림 기록과 푸시 알림 토큰

탈퇴 시 함께 처리되는 것

  • 내가 연 모집 중인 미팅은 취소되고 참가자에게 알림이 갑니다.
  • 내가 신청·참가 중인 모집 중 미팅은 참가가 취소되고 호스트에게 알림이 갑니다.
  • 내가 호스트였던 지난 미팅은 호스트 정보만 지워지고, 다른 참가자들의 매칭·채팅은 유지됩니다.

보관되는 데이터

법령에 따라 보관해야 하는 경우에만 아래 기간 동안 보관 후 파기합니다.

  • 유료 코인 결제 기록: 5년 (전자상거래법)
  • 소비자 불만·분쟁 처리 기록: 3년 (전자상거래법)
  • 접속 기록: 3개월 (통신비밀보호법)
