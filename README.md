# veldotlabs.com
벨도트랩스 회사 홈 겸 로미 소개 페이지 (GitHub Pages, 사용자 정의 도메인 veldotlabs.com — DNS는 호스팅케이알).
스크린샷은 img/ (실기기 캡처에서 상태바 잘라냄).

## /games/ — 게임
게임 목록은 `/games/`, 게임마다 `/games/<이름>/`(소개)와 `/games/<이름>/privacy.html`(개인정보처리방침, 한국어·영어 한 페이지). 그림은 `img/<이름>/`. 새 게임을 추가하면 홈(index.html) "우리가 만든 앱"에 로미와 같은 카드 하나 (새 것이 앞, "Coming soon" 카드는 항상 맨 끝), `/games/` 에도 카드를 같이 넣는다.

| 주소 | 내용 |
|---|---|
| /games/waterheroes/ | Water Heroes 소개 (Play 출시 준비 중) |
| /games/waterheroes/privacy.html | Water Heroes 개인정보처리방침 (Play 콘솔과 게임 설정 ▸ 게임 정보에 연결됨) |
| /games/waterheroes/terms.html | Water Heroes 이용약관 (게임 설정 ▸ 게임 정보에 연결됨) |
| /waterheroes/privacy.html | 옛 주소, 위로 넘김 (지우지 말 것) |

## /dl/ — 출시 전 비공식 자료 (링크 전용)
홈·앱 소개 어디에도 링크하지 않고, 아는 사람에게 주소만 전달. 검색 노출 막음(robots.txt `Disallow: /dl/`, 페이지는 noindex).
새 비공식 앱·APK·시험 페이지도 전부 여기(`dl/이름…`)에 둔다. 루트에 새 폴더 만들지 말 것.

| 주소 | 내용 |
|---|---|
| /dl/holdem/ | 홀덤 데이터 분석 v2 (옛 주소 /holdem/ 은 여기로 넘김) |

주의: 이 저장소는 공개라 GitHub에서는 파일이 보인다. 비밀값 금지. APK는 올릴 때마다 기록에 쌓여 저장소가 커지니(GitHub 파일당 100MB 제한) 너무 자주 올리지 않기.

워터히어로즈 APK는 2026-10-30 사용자 요청으로 삭제(다시 올리지 않음).
