작심3일 계정 및 데이터 삭제 요청

앱: 작심3일 (com.jaksim.threedays) · 개발자: skylife0407 · 시행일 2026-04-23

작심3일 앱은 사용자가 언제든지 계정과 관련 데이터를 직접 삭제할 수 있도록 두 가지 경로를 제공합니다.

방법 1 — 앱 내에서 직접 삭제 (권장)

  1. 작심3일 앱 실행
  2. 하단 탭 중 "프로필" 선택
  3. 화면 하단의 "회원 탈퇴" 버튼 탭
  4. 확인 대화상자에서 "탈퇴" 확인

이 경로를 거치면 아래 "삭제되는 데이터" 항목이 즉시 제거됩니다. 탈퇴 후 별도 복구 절차는 없습니다.

방법 2 — 이메일로 요청

앱에 접근할 수 없거나 앱을 설치하지 않은 상태라면 아래 이메일로 삭제를 요청할 수 있습니다.

contact@veldotlabs.com

요청 시 다음 정보를 함께 보내주세요.

  • 작심3일 가입 시 사용한 Google 계정 이메일 주소
  • 제목: [작심3일] 계정 삭제 요청
이메일 요청은 접수 후 영업일 기준 7일 이내에 처리됩니다. 처리 완료 시 답신 메일을 보냅니다.

삭제되는 데이터

계정 삭제 시 아래 항목이 즉시 제거됩니다.

  • Google 로그인 정보 (UID, 이메일, 프로필명, 프로필 사진)
  • 팀 챌린지 참여 기록 (팀 멤버 정보, 공유 메모, 인증 사진)
  • 팀 숲 기여 타일, 리액션 기록
  • 푸시 알림 토큰 (FCM)
  • 숲 포인트 지갑
  • 차단 목록

보관되는 데이터

아래 항목은 서비스 운영상 필요 또는 법적 의무에 따라 제한된 기간 동안 보관됩니다.

  • 신고 기록 — 본인이 신고한 또는 타인으로부터 신고된 내역. 허위 신고·악용 방지 목적으로 최대 90일 보관 후 자동 삭제됩니다. 사용자 식별자는 삭제 시점에 비식별화됩니다.
  • 크래시 로그 (Firebase Crashlytics) — 기기 식별자 없이 익명화된 상태로 최대 90일 보관됩니다.
  • 서버 접근 로그 — Firebase 기본 정책에 따라 일정 기간 보관됩니다. 사용자 식별 정보는 포함되지 않습니다.

개인 습관 데이터 안내

작심3일의 개인 습관 기록(체크인 날짜, 메모, 사진)은 기본적으로 사용자의 기기에만 저장됩니다. Google 계정을 연결하지 않아도 앱의 개인 기능은 완전히 동작하며, 이 데이터는 앱 제거 시 함께 삭제됩니다.
